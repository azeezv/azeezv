## 🚀 Featured Projects

### [Chatqik](https://chatqik.com) — AI Customer Support
`TypeScript · Node.js · PostgreSQL · Qdrant · Mastra · Vercel AI SDK`
Multilingual RAG chatbot for WhatsApp & web with a 7-step Mastra orchestration pipeline — triage, safety guardrails, human escalation, Whisper speech-to-text, and custom voice-clone TTS (QWen3).

### [Athleon](https://athleon.in) — Electronic Shooting Target Software
`Rust · Tauri · Flutter · AWS · CI/CD`
Cross-platform software for Athleon's electronic shooting targets: Windows and macOS desktop apps built with Tauri, iOS and Android apps built with Flutter, and a custom low-latency protocol for communicating with the target hardware. An AWS backend syncs every shot to the cloud in real time, so remote viewers can follow a session live in the web app.


### [Remawt](https://renawt.vercel.app/) — AI Motion-Graphics Video
`LangGraph · FFmpeg · Remotion · BullMQ · Node.js`
AI-driven motion graphics video generation platform with LangGraph orchestration for scene planning and asset generation, Remotion rendering pipeline on dedicated VPS nodes, and BullMQ-backed job queues for reliable async rendering at scale.

### [ReelsFly](https://reelsfly.com) — AI Video Platform
`Next.js · Python · FFmpeg · Stable Diffusion · TTS`
End-to-end AI video generation with a "Story Mode" that automates the full pipeline: storyboard → scene composition → video synthesis → audio.
